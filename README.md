## Đã chốt

- Thuyết trình **15 phút, bao gồm demo**.
- Không bắt buộc framework; chọn Kotlin native để quan sát cơ chế Android trực tiếp.
- Thiết bị: **OPPO Find X9 và máy ảo Android**. Chưa kiểm tra phiên bản Android/ColorOS hoặc môi trường build.
- 80% công sức cho cơ chế, demo và thực nghiệm; 20% cho nghiên cứu, lập luận và đối chiếu tài liệu.
